# BlogHub - Full Stack Blog Application

## 📌 About the Project

BlogHub is a full-stack blog application that allows users to register, log in securely, create blogs, and manage their personal blog dashboard.

## ✨ Features

- User Registration
- User Login
- JWT Authentication
- Protected Dashboard
- Create Blog
- View Blogs
- User Profile
- Logout
- User-specific blogs
- Responsive design for mobile and desktop

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- JWT Authentication
- CORS
